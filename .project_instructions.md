## Local LLM Chat — Project Architecture

### Design
- Dark-first theme with signal teal (#4DB6A8) brand color, dark bg #0E1113
- Inter (400/500/600) + JetBrains Mono (400/500) fonts
- Flat surfaces, hairline borders, no gradients/shadows
- userInterfaceStyle: automatic in app.json, defaults to dark, supports light/system toggle
- Paper MD3 theme + custom appColors extension

### Navigation
- expo-router Stack (no tabs), drawer is a component inside index.tsx using react-native-drawer-layout's `Drawer`
- Screens: index (chat), chat-settings, search, models, settings/index, settings/presets, help, +not-found
- No auth, no accounts, fully offline

### Data Layer
- expo-sqlite for all persistence (via platform-specific loader: sqliteLoader.ts / sqliteLoader.web.ts)
- Tables: settings (KV), models, sessions, messages, messages_fts (FTS5 with triggers), prompt_presets
- GenParams: temperature, topP, topK, minP, repeatPenalty, maxTokens, contextLength, threads

### Inference
- llama.rn for on-device GGUF model inference (native only)
- Template system: auto (jinja from file), ChatML, Llama 3, Gemma, Mistral, Phi, Zephyr, Vicuna, Alpaca, raw
- Web shows notice: "On-device inference requires the Android app"

### Key Patterns
- SettingsContext + ModelContext for global state
- FlashList v2 (no estimatedItemSize prop, no inverted prop in types)
- DrawerLayout API: drawerStyle for width, renderDrawerContent (not renderNavigationView)
- All expo-sqlite imports go through lib/sqliteLoader (platform-split) to prevent web export errors
- Unicode chars written directly in JSX (no \uXXXX escapes)
